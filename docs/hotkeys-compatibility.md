# 快捷键与工作台适配

账户设置 `/user/account/hotkeys` 中的快捷键用于数据管理和独立标注工作台。项目覆盖优先于账户设置；切换项目后重新加载对应配置，离开项目后清除覆盖。

独立工作台默认使用 Ctrl+Enter 提交并领取下一条、Ctrl+Space 跳过。查看预测时，提交键执行“接受并继续”；编辑已有人工标注时更新原记录。查看已提交结果时不会再次提交，需先点击“修改当前标注”。快捷键与按钮共用校验、草稿保存、任务占用和错误反馈流程，连续按键不会并发提交。

撤销、重做、区域选择、删除、关系及工具快捷键由编辑器处理。只读预测和已提交结果不能通过快捷键修改。输入框、文本域及可编辑文本内保留文字编辑行为，中文输入法组合输入不会触发标注操作。数据管理导航在文本标注面板打开时仍可用；同一按键被当前图像、时间序列等工具占用时，编辑器优先。

快捷键录制统一保存空格、方向键、Shift+数字/标点和 Command 的运行时名称。可用设置开关禁用单项，禁用后提示不显示按键；编辑器总开关在刷新后仍生效。历史设置中已保存为 `arrowleft` 等名称的绑定仍可识别；历史空格录制产生的不完整组合需要重新录制保存。

复盘修复点：

- 新工作台遗漏账户/项目键位初始化及提交、跳过绑定。
- 编辑器异步初始化后全局快捷键入口丢失。
- 段落分组未转换为编辑器键位配置。
- 禁用键位为空时工具提示报错。
- 数据管理无条件屏蔽导航键、导航提示文案复制错误。
- 列表首尾继续导航误关标注面板，领取下一条后的重复请求覆盖刚选择的结果视图。
- 录制名称与执行库不一致、别名解绑失效、数字小键盘丢失修饰键。
- 只读结果的修改快捷键和总开关刷新状态未统一保护。

图像、音频、视频、时间序列、段落和审核专用动作仅在对应控件或审核模式提供该操作时生效；设置页中的键位不会开启项目没有配置的功能。

验证：Docker 构建执行键位录制、账户/项目合并及本地化单元测试；`tests/browser/hotkeys.spec.cjs` 在 SQLite、MySQL CI 矩阵中执行实际浏览器按键、保存、刷新、工作台及数据管理回归。其余工作台、预标注、翻译、模型、加载和语言回归继续运行。
