# 大数据项目加载

首屏只请求项目配置与“是否有样本”，完整总数在样本出现后异步刷新；同一加载阶段的项目请求合并为一次。同一用户的短时间路由切换复用配置，保存设置时强制刷新。普通列表省去个人标注队列的扫描，进入标注流时仍读取完整队列。项目完成数用明确的布尔值条件匹配已有复合索引做独立计数，避免把全部样本与项目联表分组；个人完成数只对标注记录中的任务 ID 去重。

样本仍按页加载并使用虚拟列表，统计口径、筛选条件和行排序保持不变。项目卡片先显示基本信息，统计加载时显示占位；打开项目时提供加载状态，初始化失败可重试。

本机只读性能测量：在现有 Node 环境运行 `node tools/measure-project-loading.cjs`。默认测量项目 4，可通过 `PERF_PROJECT_ID` 指定其他项目；`PERF_REPORT` 指定 artifacts 中的报告文件名。会打开项目列表、目标数据页并刷新一次，只保存请求耗时和大小，不保存 Cookie、密钥或样本原文。基线与优化后应使用相同数据、浏览器和服务环境比较。
