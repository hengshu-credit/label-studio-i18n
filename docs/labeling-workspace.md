# 独立标注工作台

入口是项目数据页顶部的“标注工作台”，或 `/projects/<项目ID>/label`。模型工作台的“使用结果并开始标注”也进入这里。

## 三种结果状态

- **模型预标注**：保留原始预测及模型、置信度，是只读建议。浏览不会生成正式标注。
- **标注草稿**：领取样本后直接编辑，也可从预览点击“修改预标注后提交”或“从头人工标注”；修改定期保存，也可手动保存。草稿不会计入完成数量或自训练数据。
- **已提交人工标注**：点击“接受并下一条”或“提交并下一条”后产生。保留标注人、时间及来源预测；原预测仍保留供比较。

同一人在工作台对同一任务提交过结果后，应编辑自己的人工标注。重复点击或网络重试不会新增重复标注，也不会覆盖其他人的结果。修改前会核对任务内容、标注配置和标注更新时间；其他窗口已保存的草稿或人工标注不会被静默覆盖。

人工确认不等同于设置为评估用的 Ground Truth。是否作为评估样本仍由项目的数据和质量设置决定。

## 领取与分配

“领取下一条样本”才会领取工作，预览链接不会自动提交结果。可以保存草稿并释放样本，或按项目规则跳过。默认提交成功后自动领取下一条。主按钮右侧菜单可选择“提交并查看结果”或“提交并退出”，接受预标注也有对应选项；可通过“查看已提交结果”与“标注历史”回看自己的结果。按钮、菜单、主题与全局导航复用 Label Studio 原生组件。

项目管理者可以在“样本分配设置”中配置：

- **自动分配**：沿用项目常规设置的顺序、随机、不确定性采样。仅有预测的任务仍可领取。占用生效期间，其他人不能抢占该标注名额；达到所需标注人数后移出队列。
- **指定成员分配**：填写样本 ID 并选择成员。成员只领取自己的分配任务，按任务 ID 排序；同一任务指定多人时，需所有指定成员完成才算完成。单次最多 5000 个样本、100 位成员，且最多 10000 组样本与成员关系。
- **占用时长**：1–1440 分钟；前台工作期间会续期。过期后仍能保留个人草稿，但必须重新取得有效占用才能正式提交。
- **跳过规则**：交给其他人、排到自己的队尾，或按配置将跳过计为完成。跳过结果不会当作正式标签进入训练。

已有占用时，先完成或释放任务，再改变分配设置。数据管理页保留快速查看和管理功能；日常分配式标注使用独立工作台。历史人工标注不会因升级被合并、删除或改写。

## 验证与实现

后端复用 Label Studio 的采样和任务占用模型；SQLite 领取/提交前先取得写锁，其他数据库使用行锁，避免并发领取超出容量。新增表只保存工作台配置、成员分配和个人草稿，预测和正式标注仍分别存入原有 Prediction 和 Annotation 表。

自动化验证覆盖真实数据库并发领取、预标注接受、幂等提交、草稿恢复、过期占用、必填字段、来源预测归属、版本冲突及人工分配。浏览器测试覆盖完整操作与跨项目设置切换。

交互参考 HumanSignal 的公开[项目设置与任务分配文档](https://docs.humansignal.com/guide/project_settings_lse)，由本仓库基于现有开源代码实现。

## 当前样本预标注与结果页签

标注工作台和数据管理的快速标注界面都提供“预标注当前样本”：选择项目中配置的模型，点击后只处理当前样本，结果作为模型预标注显示，复核后再接受或修改提交。也可点击“直接人工标注”开始人工处理；已有自己的正式结果时进入编辑，避免重复创建。模型调用沿用原有请求限额和后台任务恢复机制。

结果页签右侧的 × 只关闭视图，不删除预测或正式标注。修改中的草稿先保存，保存失败时保留页签。可通过“恢复已关闭页签”重新显示；全部关闭后仍可对当前样本预标注或直接人工标注。

## 编辑与样本列表

领取样本后直接进入可编辑草稿；有模型预标注时作为草稿起点，提交前不会生成正式人工标注。点击左侧模型结果可只读对比，再通过结果区顶部的「修改预标注后提交」继续编辑。已提交结果顶部提供「修改当前标注」，保存时更新原记录。实体标注先选择标签，再拖选原文；选中已有实体可以修改标签或删除。

样本列表默认列依次为 ID、sample_id、content、预测模型版本、预测结果、预测分数、标注数、跳过数、预测数、标注员、已完成。项目实际使用的其他输入字段仍可显示；其他元数据默认隐藏，可在「列」中打开。已有默认视图一次性更新列布局，筛选条件和样本排序保留；自定义视图保持原配置。
