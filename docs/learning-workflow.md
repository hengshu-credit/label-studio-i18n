# 模型与预标注工作台

入口：项目设置 → 模型与预标注。所有服务、处理任务、复核决定、数据快照及训练模型按项目隔离。

## 日常操作顺序

1. 打开“模型管理”，选择“添加模型”或“复用其他项目模型”。云端填写模型 ID、密钥；本地 Transformers 填模型路径，并明确选择已训练任务模型或需要先训练的纯基座。
2. 保存后在模型卡片点“试跑 1 条”，直接查看原文、模型建议和已有人工标注。失败时查看错误，调整配置后重试。
3. 点“生成预标注”，选择样本范围和数量，再“批量生成预标注”。已有人工标注的项目选择“全部样本”可比较效果。
4. 结果完成后点“使用结果并开始标注”，进入标注编辑器。长版本号、JSON 与旧连接管理放在高级工具中。
5. 在“自训练”选择当前项目模型，用已提交人工标注训练；查看验证指标，再发布候选版本。在“难样本复核”检查分歧、修正标注并确认复核，修正才进入下一轮训练。

旧的 `/settings/ml` 与 `/settings/predictions` 书签自动进入统一工作台的对应页签。

## 模型复用和移除

“复用其他项目模型”列出同组织、当前用户有权访问的模型。复制后形成当前项目的独立配置；云端密钥在服务端加密复制，不回显。任务提示词默认不复制，避免混入其他项目的标签定义。

本地 Transformers 可选择从源项目当前已发布权重开始，也可只复用基座配置。已发布检查点作为只读起点，目标项目用新的项目和连接身份保存后续权重，源项目不受影响。目标项目标签需兼容；不兼容时连接校验明确报错。需要重新定义标签时使用基座配置并选择“先训练”。

“编辑配置”保留留空的已有密钥。运行中的模型须完成或取消任务后才能编辑或移除。“从本项目移除”经确认后清除当前配置中的凭据、停用调度；已有标注、预测、训练历史与磁盘检查点保留，其他项目不受影响。这个操作不会删除源模型文件。

## 预标注

“模型管理 → 添加模型”可添加 OpenAI、DeepSeek、公开 HTTPS 的兼容 Chat Completions 服务，或本地 ML / Transformers 模型。云端使用用户填写的模型 ID，不替用户选定或升级收费模型。API 密钥按服务器 Secret Key 加密，接口仅返回是否已配置；更换服务地址/类型会清除旧密钥，避免发送到错误服务。

本地 OpenAI 兼容大模型服务可选择“本地大模型（兼容 API）”，例如 `http://host.docker.internal:11434/v1/chat/completions`。仅允许显式开启本地 ML 访问后的回环地址，不能借此访问任意内网地址；密钥可选。

云端返回 Label Studio result JSON，经过控件名、目标名、标签集合、实体字符偏移校验后才保存 prediction。OpenAI 默认请求严格 JSON Schema；DeepSeek 使用 JSON 模式并由服务器进行同样的最终校验。拒绝、截断、非法 JSON、越界实体和网络错误进入失败队列。云端自报不确定作为复核信号，不伪装成概率分数。

任务完成后点击“使用结果并开始标注”，把这一批的预测版本设为标注编辑器建议来源；原人工标注不会被覆盖，未处理样本不会自动向云端发起请求。

创建任务时明确选择样本范围及最多处理条数，默认 100，上限 5000。每个项目同时执行一个任务；任务逐项保存进度，重启后续跑，重试不会重做成功项。失败重试由用户显式触发，仍计入每月请求上限；请求失败也保守计费次。本地服务无需云端密钥。后台 worker 每批处理 32 条，在任务之间检查取消。

## 难样本与复核

难样本池区分低置信度、模型分歧、人工纠正、模型自报不确定、预测失败和人工标记。可查看原文、最近三个预测及人工标注。点击“打开标注编辑器”修改并提交，再回工作台“确认复核”，或者排除该样本参与训练。记录复核人、时间、备注及标注摘要；重新分析不会反复打开相同证据已解决的样本，新的预测或纠正会重新进入复核。

普通标注的人工修改也会自动分析是否与预测不同。保留评估集通过任务 data 的 `_workflow_split: "holdout"` 标记，禁止进入训练。该字段不发给云端模型；只发送标注控件实际引用的原文。

## 项目独立训练

在“模型管理 → 添加模型”选择 Transformers，填写模型路径或 Hugging Face ID。新界面自动使用工作台调度，避免同时运行两套训练流程。选择支持 Sequence Classification / BIO Token Classification 的模型及 fast tokenizer；使用纯基座时明确配置 `initialize_head: true`。

训练采用当前项目已提交人工标注的固定快照，排除保留评估集、未复核/排除的难样本。快照排队后数据、标注、模型配置或复核决定变化时任务失败并要求重新创建，不在运行中偷偷更换训练数据。任务详情显示训练步数、损失、训练/验证数量以及训练前后 accuracy、macro F1。

验证集按规范化文本模板分组，避免数字/URL 变体跨训练验证集。验证比例 20%；NER 的指标是 token 层面的准确率和 macro F1，并非实体级 F1。小样本可能没有独立验证组，此时指标为空，不能解释为质量通过。

训练输出候选检查点，当前模型保持可用；检查指标后点击“发布此模型”。发布 API 校验项目和模型配置身份，禁止把其他项目的候选版本发布到当前项目。原始基座不被覆盖，历史版本保留；每轮从基座完整回放选定训练快照。取消在优化步骤边界生效；失败或取消不发布半成品。

## 部署与验证边界

Docker Compose 中 `active-learning` 进程负责持久任务。Linux 文件锁确保共享数据目录只有一个工作进程。本机 Transformers 服务使用既有 Anaconda base；CPU CI 使用小型合成 checkpoint 验证实际梯度更新、版本发布、项目隔离及错误保护。

API 契约测试使用模拟云端响应，只有配置真实账户并调用成功后才能宣称对应云端服务通过真实验收。每月限额是本系统请求计数，不等于服务商账单。文本单条最长 12000 字符，训练仍受模型 token 长度上限及显存限制；超限明确失败，不自动截断原文或实体。

生产实例需备份 Label Studio 数据卷、Secret Key 和本地模型输出目录。此部署面向单机共享数据卷；多节点分布式 GPU 调度、大规模离线训练、云端微调及多人复核仲裁不在本实现范围内。

参考：[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat)、[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。


## 结果与固定保留集诊断

每个任务可下载包含完整预测内容的 JSON，避免旧版导出接口只返回预测 ID。预标注及分析完成后，工作台按模型、控件及保留集/标注集显示准确率、Macro F1、覆盖数量和常见混淆。只统计输入哈希仍匹配的工作台预测；没有足够人工参考标签时不制造分数。不同任务的内部验证子集可能不同，比较模型版本应使用相同保留集及 cohort_hash。

## Windows 后台运行

`tools/install-transformers-task.ps1` 注册当前用户登录启动任务 `LabelStudio-Transformers-9092`，使用既有 Anaconda base 的 pythonw，无可见终端；异常退出最多自动重启 5 次。`tools/run-transformers.pyw` 将日志写入 `ml_backend/data/logs`，不记录访问日志。安装后先停止手动启动的同端口实例，再执行 `Start-ScheduledTask -TaskName LabelStudio-Transformers-9092`。可用 `Stop-ScheduledTask` 停止。该方式依赖用户登录，适用于当前 Docker Desktop 单机部署。

默认容器现在使用镜像内置的 Nginx + uWSGI，启动前执行初始化与迁移；保留外部 8080 端口及原有数据挂载。任一服务器退出都会终止同容器另一服务器，由 Compose 重启策略接管。未修改宿主机 Nginx、证书或防火墙。错误上报 DSN 默认关闭；云端文本发送只发生在显式启动的服务任务中。

旧的自动主动学习开关同样排除保留评估样本与未确认的难样本，并在本项目存在工作台任务时让出执行机会。推荐使用工作台候选发布流程来检查效果并保留发布选择。

默认预标注范围是“未标注且没有当前模型预测”，便于连续处理下一批，避免重复消耗同一版本的请求。也可指定任务 ID 或显式重跑全部样本。服务卡支持先试运行 1 条。鉴权、额度或服务不可用会暂停任务并保留未处理队列；提高请求额度或轮换密钥后可重试，修改模型/提示词则需创建新任务。

DeepSeek 服务可配置思考模式及采样温度，默认关闭思考、temperature=0，适合直接输出标注 JSON。启用思考时不发送 temperature，并应留足 max_tokens；更改这些推理参数会形成新的预测配置身份。默认模型示例为 deepseek-flash，使用者填写的模型 ID 会原样保留。
